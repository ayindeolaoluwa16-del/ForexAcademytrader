# 🤖 EducToolBot

A free Telegram utility bot with 15+ educational tools. No API keys, no data stored.

## Tools Included
- Text Case Converter
- Word & Character Counter
- Password Generator
- UUID Generator
- Lorem Ipsum Generator
- Base64 Encode/Decode
- URL Encode/Decode
- Hash Generator (MD5 / SHA1 / SHA256)
- Text Reverser
- Text ↔ Binary Converter
- BMI Calculator
- Age Calculator
- Percentage Calculator
- Random Number Generator
- Slug Generator

## Commands
- `/start` — Show the tool menu
- `/help` — Usage instructions
- `/cancel` — Exit the current tool

## Local Run

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="your_token_here"
python main.py
